## ✨ Features

- 🖤 Sleek dark-themed UI with smooth gradients
- 🧭 Multi-page navigation — Home, Products, About, Contact
- 🤖 Animated 3D robot visuals
- 📱 Responsive layout
- 🔐 Login / Sign Up flow
- 📩 Contact form with Name, Email & Message fields
